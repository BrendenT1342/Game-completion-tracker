# Game Completion Tracker

A simple web app for keeping track of video games you want to play, in progress, and have finished. Ideally keep track on games you've have it backlog or forgotten to finish the game.

Built with plain **HTML, CSS and JavaScript**, no frameworks needed.

## Features

- Add games to your list
- Attach an image to each game (e.g. cover art)
- Mark games as completed
- Clean, simple styling that works in any modern browser

## Getting Started

### Run it locally

1. Clone the repository:
   ```bash
   git clone https://github.com/BrendenT1342/Game-completion-tracker.git
   ```
2. Open the project folder:
   ```bash
   cd Game-completion-tracker
   ```
3. Open `index.html` in your browser. Or, if you use VS Code, right-click it and choose **Open with Live Server**.

No installation or dependencies required.

## How to Use

1. Type the name of a game into the input field.
2. Choose an image for the game using the image input.
3. Click **Add** to put it on your list.
4. When you finish a game, mark it as completed.
5. If you accidently mark the game complete you can undo the actions back to incomplete game list
